SOURCE-BASED BROWSER ADAPTATION

Small C++ exercises, now interactive.

The original C++ programs were group coursework in 2023/24. These AI-assisted browser adaptations were created later from the archived source; they are not the original submissions.

Calculate using German number words

Supports German number words from null to ten, arithmetic operations and two division modes. Integer division truncates toward zero, as in the original C++ program.

Examples: eins plus zwei · acht mal drei · sieben geteilt-durch zwei · sieben dividiert-durch zwei

Enter an expression and select Calculate.

    Sort three values using Bubble Sort

    The two passes and adjacent comparisons follow the loop structure of the archived C++ submission. This visualizes the algorithm, not a newly developed sorting library.

      Origin: The archived originals compile under C++17. The browser interface and visualization were created separately in 2026 with AI assistance; the C++ sources remain unchanged. Group contributions are not represented as individual authorship.
