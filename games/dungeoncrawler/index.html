Original mechanics

  • Randomized 20×20 dungeon levels
  • Skeletons and bats move after your turn
  • Chests contain gold and healing
  • Bats can poison the player
  • Mage teleport costs 100 gold
  • Reach the gate to advance

About this version

The original project ran as C++ code with AlgoViz. This version ports the core gameplay to JavaScript so it can be played directly on NotedBit.
