C++ Library Management Application

Archived C++17 coursework with domain classes for books, authors, users and borrowing; the original command dispatcher was not completed.

C++17OOPSTLFile I/O

2024 · Archived source, not completeCompiles · Not functional end-to-end

Multiple domain classes

The January 2024 source archive contains Book, Author, User, Tag, BorrowEntry and Library classes, separate translation units, standard containers and file-I/O methods. This is a source-code case study, not a finished usable app.

Missing command dispatch

The original command dispatcher Library::processCommand() is empty and a borrowing-permission method is a placeholder. A separate conceptual browser demo would not accurately represent what the original C++ program could do, so none is advertised.

The origin of individual source contributions should be verified before publishing the original code.
