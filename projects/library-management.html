C++ Library Management Application

A multi-class C++ application skeleton for managing books, authors, users and borrowing records. The command interface is unfinished.

C++17OOPSTLFile I/O
Type
C++ coursework / archived source
Status
Compiles · Not functional end-to-end

Structure

Multiple domain classes

The archived code contains separate Book, Author, User, Tag, BorrowEntry and Library classes, with header/source separation, standard containers, lookup routines and file-I/O methods.

Limitations

Missing command dispatch

The main input loop calls Library::processCommand(), but that method has no implementation in the available archive. A borrowing authorization check is also a placeholder. A successful build therefore does not mean the application is usable.

Publication

No misleading demo

The project is documented as unfinished coursework. The origin of individual code portions and the complete feature set should be checked before publishing source files or presenting a runnable demo.
