TrendingTrove

TrendingTrove (ProductVideoGenerator) is a Python-based application for automating short product videos with local text generation, speech synthesis and video rendering.

  • Python
  • Qwen
  • Kokoro TTS
  • FFmpeg
  • Linux

Simplified workflow

  1. Product input and research
  2. Script generation with a local language model
  3. Narration using local TTS
  4. Video composition and rendering with FFmpeg

Process diagram, not an application screenshot

What has been tested

Local end-to-end pipeline

A complete run generating a short vertical video has succeeded on Linux. The pipeline combines local text generation, Kokoro narration and FFmpeg-based video output.

Current status

Still in development

The Linux workflow has been tested, but the application and its Windows packaging are still being refined. There is no public release or repository linked from this page.

Context

Why this project

The main engineering focus is connecting text, speech and video processing into one repeatable local workflow, rather than demonstrating a standalone AI model.
