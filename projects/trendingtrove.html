Python application · In development

TrendingTrove

A local-first application for producing short product videos. Python coordinates product data, script generation, speech synthesis, scene composition and video encoding in a single workflow.

  • Python
  • Qwen
  • Kokoro TTS
  • FFmpeg
  • Linux

Processing pipeline

  1. Collect product information and images
  2. Generate and check script text with local Qwen
  3. Synthesize narration with Kokoro TTS
  4. Assemble scenes, captions and timings
  5. Render and validate an MP4 with FFmpeg

Implementation

Connecting the components

Python orchestrates local language-model inference, narration, storyboard timing and FFmpeg rendering. The workflow also checks script claims and performs technical checks on the exported video.

Development status

Working prototype, ongoing refinement

Linux end-to-end generation has been demonstrated. Windows launch and generation still require final verification; subjective narration quality and publishing-platform acceptance are not claimed as validated.

Project scope

Local production workflow

The objective is a repeatable pipeline that converts product information into a timed, narrated vertical video without requiring external language-model API keys. The application and its distribution packages remain under development.
