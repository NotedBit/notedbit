Automated Video Production

Python desktop application combining local language models, speech synthesis and FFmpeg to produce short vertical product videos.

What the sample shows

Generated product scenes, visual variations, narration, captions and an ending call to action. The sample is an earlier development iteration and contains visual and category-selection limitations.

The separately documented Linux test was performed on a different output file. Its validation results do not certify this sample.

From product information to video output

The application is designed to generate narrated vertical product videos from selected product data. Python coordinates data processing, local text generation, audio and rendering in an end-to-end workflow.

Pipeline components

The pipeline uses a local Qwen model for scripts, Kokoro for speech synthesis and FFmpeg for video rendering. Scene timing, captions, composition and technical checks are handled within the application. A PySide6-based desktop interface is part of the project.

What has been verified

The embedded video is byte-identical to the saved visual reference from the original project. The repository snapshot includes Python pipeline modules for product discovery, Qwen scripting, audio, storyboards, rendering and quality checks; this does not imply a fresh end-to-end render was run here.

Current development work

Development patches aim to keep every generated video within one product category, improve voice naturalness and refine subtle motion. The single-category patch and full AI runtime have not been successfully exercised in this environment because its development dependencies and secrets are not present in the filtered source snapshot.
