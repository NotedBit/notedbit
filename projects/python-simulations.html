Independent development project

Python Simulation & Video Generation

Physics-driven, reproducible Python/pygame simulations with nine registered modes, configurable recipes and run-quality checks. Three mechanics are available as a separate live browser adaptation.

Pythonpygame-ceEventsCollision logic

2026 · Development workSimulation core tested · Full workflow in development

Simulation mechanics

The Python source registers nine modes: Escape / Multiplication, Fibonacci / Merge, Bounce Evolution, Shrinking Circle, Power Doubler, Mass Collision Counter, Plinko, Polygon Evolution and Multiplier Rings. The last mode is explicitly marked experimental.

Events and reproducibility

A mode registry, configurable recipes, seeded runs, collision helpers, event listeners and run-quality metrics are implemented in Python. The original pygame application could not be started in this test environment without pygame-ce.

Target workflow versus completed features

The intended one-click flow includes simulation, quality checks, optional retries and final MP4 export. Available documentation verifies the simulation core; it does not establish that every planned end-to-end video step is complete.

Interactive browser demo

Escape / Multiplication, Plinko and Shrinking Circle recreated as a separate browser adaptation. Switch modes and adjust gravity, seed and speed.
